# Анализ дорожной разметки с YOLOv8 и Qwen2.5-VL

Проект позволяет анализировать изображения дорожной разметки с помощью **YOLOv8** для детекции областей и **Qwen2.5-VL-3B-Instruct** (Vision-Language Model) для оценки состояния разметки, износа и потенциального риска.

### Подготовили **Каратеев Георгий**, **Шоколов Антон**, **Новикова Полина**

---

## 📂 Структура проекта
```
├── app/
│   ├── app.py            # Основное Streamlit-приложение
│   ├── vlm_processor.py  # Обертка для VLM (Qwen2.5)
│   └── yolo_processor.py # Обертка для YOLO
├── yolo/                 # Папка с моделью YOLO (.pt), а также скрипты для тренировки
├── requirements.txt      # Python-зависимости
└── Dockerfile            # Dockerfile для сборки контейнера
```

---

## ⚡ Требования

- **Docker** (с поддержкой NVIDIA GPU) или Python 3.12+ локально
- **GPU с CUDA**: Минимум **8 ГБ VRAM** (оптимально для Qwen2.5-VL-3B).
- В папке `yolo/` должна лежать ваша обученная модель YOLO `.pt`.

---

## 🚀 Локальный запуск без Docker

1. Установить зависимости:
```bash
pip install -r requirements.txt
```

2. Запустить Streamlit:
```bash
streamlit run app/app.py
```

3. Открыть браузер по адресу:
```bash
http://localhost:8501
```

---

## 🐳 Запуск через Docker (рекомендуется) (Но много весит)

1. Сборка образа:
```bash
docker build -t my_streamlit .
```

2. Запуск контейнера с GPU:
```bash
docker run --gpus all -p 8501:8501 my_streamlit
```
* `--gpus all` — пробрасывает видеокарту для PyTorch
* `-p 8501:8501` — пробрасывает порт Streamlit на хост

---

## ⚙️ Настройки Streamlit

* **Порог уверенности YOLO** — регулируется слайдером (0.1–1.0).
* **Промпт VLM** — можно редактировать в текстовом поле для изменения критериев оценки.
* Вкладка **«Настройки»** — скрывает технические параметры и позволяет редактировать промпт.

---

## 🖼️ Использование

1. Загрузите изображение (png, jpg, jpeg).
2. Нажмите **Начать анализ**.
3. Streamlit покажет:
    * Обнаруженные объекты YOLO (кропы).
    * Результаты анализа VLM (износ в %, риск аварии, рекомендация по ремонту).
    * JSON-ответ модели.
    * Координаты bounding box.
    * Мониторинг использования VRAM в боковой панели.

---

## ⚠️ Замечания

* Первая загрузка весов модели **Qwen2.5-VL-3B** (~6 ГБ) может занять несколько минут.
* Работа на **CPU** возможна, но анализ будет проходить очень медленно.
* Рекомендуется использовать видеокарту с **8 ГБ видеопамяти** или больше для быстрой обработки.
