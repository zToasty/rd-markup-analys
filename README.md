# Анализ дорожной разметки с YOLO и VLM

Проект позволяет анализировать изображения дорожной разметки с помощью **YOLO** для детекции областей и **VLM (Vision-Language Model)** для оценки состояния разметки и потенциального риска.

Подготовили **Каратеев Георгий**, **Шоколов Антон**, **Новикова Полина**

---

## 📂 Структура проекта
```
├── app/
│ ├── app.py # Основное Streamlit-приложение
│ ├── vlm_processor.py # Обертка для VLM
│ └── yolo_processor.py # Обертка для YOLO
├── yolo/ # Папка с моделью YOLO (.pt)
├── requirements.txt # Python-зависимости
└── Dockerfile # Dockerfile для сборки контейнера
```

---

## ⚡ Требования

- **Docker** (с поддержкой NVIDIA GPU) или Python 3.12+ локально
- **GPU с CUDA на 16GB VRAM** желательно для VLM 7B (CPU очень медленный)
- В папке `yolo/` должна лежать ваша модель YOLO `.pt`

---

## 🚀 Локальный запуск без Docker

1. Установить зависимости:

```bash
pip install -r requirements.txt
```
2. Запустить Streamlit:
```bash
streamlit run app/app.py
```
3. Открыть браузер по адресу:
```bash
http://localhost:8501
```

## 🐳 Запуск через Docker (рекомендуется)
1. Сборка образа 
```bash 
docker build -t my_streamlit .
```

2. Запуск контейнера с GPU
```bash
docker run --gpus all -p 8501:8501 my_streamlit
```

* --gpus all — пробрасывает все GPU для PyTorch

* -p 8501:8501 — пробрасывает порт Streamlit на хост
---
## ⚙️ Настройки Streamlit

* Порог уверенности YOLO — регулируется слайдером (0.1–1.0)

* Промпт VLM — можно редактировать в текстовом поле

* Вкладка «Настройки» — для управления порогами и промптом
---


## 🖼️ Использование

1. Загрузи изображение (png, jpg, jpeg)

2. Нажми Начать анализ

3. Streamlit покажет:

    * Обнаруженные объекты YOLO

    * Результаты анализа VLM (износ, риск аварии, комментарий)

    * JSON-ответ модели

    * Координаты bounding box

---
## ⚠️ Замечания

* Первая загрузка моделей может занять несколько минут

* VLM 7B на CPU работает очень медленно

* Для корректной работы VLM рекомендуется GPU с минимум 16 ГБ VRAM

* Если отсутствует GPU, анализ будет работать, но заметно медленнее
