# Streamlit приложение для анализа дорожной разметки

Это приложение выполняет анализ дорожной разметки в два этапа:
1. **YOLO детекция** - обнаружение объектов на изображении
2. **VLM анализ** - детальный анализ обрезанных областей через Vision Language Model

## Запуск приложения

```bash
# Из корневой директории проекта
streamlit run app/app.py
```

## Структура

- `app.py` - основной файл Streamlit приложения
- `yolo_processor.py` - модуль для работы с YOLO моделью
- `vlm_processor.py` - модуль для работы с VLM моделью

## Зависимости

Все зависимости указаны в `requirments.txt` в корне проекта.

## Использование

1. Запустите приложение командой выше
2. Загрузите изображение через интерфейс
3. Настройте параметры (порог уверенности YOLO, промпт для VLM)
4. Нажмите "Начать анализ"
5. Просмотрите результаты детекции и анализа VLM
