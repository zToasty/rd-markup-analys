# Папка для YOLO модели

Поместите вашу обученную YOLO модель (файл с расширением `.pt`) в эту папку.

Приложение автоматически найдет и использует модель из этой папки при запуске.

## Примеры:
- `best.pt` - ваша обученная модель
- `yolov8_custom.pt` - кастомная модель
- `road_marking_model.pt` - модель для детекции разметки

**Важно:** Если в папке несколько `.pt` файлов, будет использована первая найденная модель.
